# Домашнее задание №1

### Содержание

- `дз1№1.py` - операции с множествами.
- `дз1№2.py` - анализ поисковых запросов.
- `дз1№3.py` - анализ заказов и возвратов.
- `дз1№4.py` - расчёт выручки и доли возвратов.
- `дз1№5.py` - анализ отзывов и рейтингов товаров.

### Требования

Python 3. Дополнительные библиотеки не требуются.

### Запуск

Из корня репозитория:

```bash
python "homework_1/дз1№1.py"
```

Для остальных задач заменить номер файла на 2, 3, 4 или 5. Каждая задача запускается отдельно.
