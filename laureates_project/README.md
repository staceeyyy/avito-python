# Анализ Нобелевских лауреатов

Проект выполняет подготовку данных, технический EDA, три темы анализа
и бонусное задание с текстами мотиваций. Расчёты написаны на обычном Python:
списки, словари, множества, циклы, функции и простые lambda.
Pandas и numpy в коде проекта не используются.

## Установка и запуск

Нужен Python 3.10 или новее. Откройте терминал в распакованной папке проекта.

```bash
python -m venv .venv
```

Активация окружения на macOS / Linux:

```bash
source .venv/bin/activate
```

Активация окружения в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установка зависимостей и полный запуск:

```bash
python -m pip install -r requirements.txt
python main.py
```

Программа выводит таблицы, а в папке `results/` создаёт семь графиков,
корпус мотиваций `motivations_corpus.json` и результаты `summary.json`.
Папка создаётся автоматически и исключена из Git как результат вычислений.

Для работы с ноутбуком и проверки оформления:

```bash
python -m pip install -r requirements-dev.txt
jupyter lab laureates_countries_solution.ipynb
```

Ноутбук нужно открывать из папки проекта: он использует соседние модули.
В нём сохранены выполненные ячейки, таблицы, графики и пояснения.
`main.py` — самостоятельная версия тех же расчётов для запуска без Jupyter.
Специальные функции анализа в ноутбуке и в `main.py` совпадают;
универсальные операции вынесены в общие модули.

## Данные и правила подсчёта

Источник: <https://api.nobelprize.org/2.1/laureates?limit=1200>.
Снимок загружен 8 ноября 2026 года; метки времени в JSON записаны в UTC.
В нём 1028 уникальных лауреатов: 1000 людей и 28 организаций;
1036 записей о награждении за 1901–2026 годы.
Сведения об условиях использования API сохранены в `meta` исходного ответа.

Для обычного запуска интернет не нужен: используется приложенный снимок.
Чтобы явно обновить его, откройте Python в папке проекта и выполните:

```python
from data_loader import load_laureates

load_laureates(refresh=True)
```

При обновлении нужно заново выполнить анализ и пересмотреть текстовые выводы
ноутбука: они относятся к приложенному снимку.

- ID и годы преобразуются в целые числа. Недоступные поля остаются `None`.
- В техническом EDA показаны общие пропуски, их доли, пропуски по типам
  лауреатов и внутри наград. Отсутствие пола у организации — неприменимое поле.
- В рейтинге стран считаются люди и организации. `country_now` — современная
  страна места рождения человека или основания организации, а не проживания.
  Записи без страны исключаются только из рейтингов стран.
- В рейтингах по категориям один лауреат считается один раз внутри категории.
  В динамике стран он относится к десятилетию своей первой премии.
- Возраст — разность года первой премии и года рождения. Это приближённый
  возраст без проверки дня рождения; организации не участвуют.
  Для сравнения категорий берётся категория первой премии.
- В гендерном анализе участвуют только люди. Общий итог содержит уникальных
  людей. В динамике человек считается один раз в каждом десятилетии, когда
  получал награду; внутри категории и десятилетия повторы также удаляются.
  Поэтому суммы по категориям/десятилетиям могут превышать общий итог.
  Доля женщин считается среди людей с известным полом.
- Для сравнения начала и конца истории используются равные интервалы:
  1901–1920 и 2007–2026. Премия по экономике появилась позднее остальных.
  Первая декада начинается с 1901 года; последняя пока неполная.
- Учитываются все статусы наград, включая `declined` и `restricted`:
  анализируется факт присуждения премии, а не подтверждение её получения.
- В бонусе одинаковая мотивация со-лауреатов одной категории и одного года
  входит в корпус один раз. Одинаковые тексты разных лет остаются отдельными.
  Слова приводятся к нижнему регистру; пунктуация отделяется пробелами.
  Частота — число вхождений слова, без объединения словоформ.
  Топ-50 строится до и после удаления стоп-слов; топ-10 категорий сравниваются
  как множества. Необязательный TF-IDF не используется.

## Проверки

```bash
python checks.py
python -m flake8 .
python -m compileall -q . -x ".venv"
jupyter nbconvert --execute --to notebook --inplace laureates_countries_solution.ipynb
```

Проверяются вложенные поля и пропуски, оба типа лауреатов, преобразование
годов, группировки по нескольким полям, агрегации, топ-N и неизменность
исходных строк при добавлении поля. При полном запуске также проверяются
число записей по `meta.count`, уникальность ID, годы и суммы наград.
В исполняемых `.py`-файлах есть `if __name__ == '__main__'`.
